# Arena Fighter (working title)

Local couch arena brawler. Godot 4.7. Small detailed pixel art (Duck Game / Broforce / Superfighters
direction) rendered with smooth sub-pixel motion.

## Art

Sprites live in `assets/sprites/` and are generated by `python3 tools/gen_art.py` (no dependencies):
fighters are a small puppet (hand-pixeled head/torso, limbs from joint angles), weapons/props are ASCII
pixel grids in that script. Team colors are magenta key pixels recolored per player. The PNGs are plain
files, so you can also just edit them in Aseprite (re-running the script overwrites them).
Terrain is baked per pixel at runtime (`scripts/world/terrain.gd`) from the 16×16 textures in `tiles.png`.

Run: open in Godot and press Play, or `godot --path .`

## Controls

Main menu: **Single player** (you vs 1–7 bots, pick difficulty and map) or **Local multiplayer** (join lobby).

| | Keyboard (single player / KB1) | KB2 | Gamepad |
|---|---|---|---|
| Move (and sweep aim while aiming) | WASD | Arrows | Stick / D-pad |
| Attack | J | Numpad 1 / `.` | X |
| Jump | K / Space | Numpad 2 / `/` | A |
| Aim / block (hold) | L | Numpad 3 / `,` | RB / RT |
| Throw / pick up | H | Numpad 0 / `;` | B (Y = pick up) |
| Sprint (hold) | Shift | Numpad Enter / `'` | LB / LT / L3 |

**Movement:** jump at a wall to grab its ledge (up/jump climbs, down drops, jump + away kicks off the
wall); knee-high obstacles are vaulted automatically while running; sprint + jump dives; sprint + down
slides (under bullets, knocks people over; jump out of a slide to keep the speed).

**Aiming (Superfighters style):** without aim, guns hip-fire straight ahead. Hold aim to stop and raise a
laser sight, then up/down sweeps it smoothly (tap for fine adjustments, hold to swing faster) and
left/right flips sides. Re-aiming within ~0.6 s keeps the last angle. Getting punched while aiming
disarms you. Rebind in `scripts/core/bindings.gd`.

**Rounds:** READY / FIGHT intro, first to 5 round wins takes the match, the winning kill plays in slow
motion. Weapons spawn at spawners and arrive by parachute supply drops (more often on big maps).

## Sound

`python3 tools/gen_sfx.py` synthesizes every effect and the music loop into `assets/sfx/` (stdlib only,
deterministic). `Sfx.play(name, world_pos)` plays one positionally; `Sfx.gun_sound(weapon_id, def)`
maps weapons to sounds (modded guns get a guess from their stats). Pass `--mute-music` to skip music.

UI text uses Russo One and Chakra Petch (SIL Open Font License, `assets/fonts/`).

## Adding weapons

Drop a `.json` file in `data/items/` (or `user://items/` for personal mods; same id overrides).
Every field in `scripts/items/weapon_def.gd` can be set. Example:

```json
{ "id": "rocket", "name": "Rocket Launcher", "kind": "gun", "color": "#556b2f", "size": [14, 4],
  "damage": 20, "ammo": 3, "fire_rate": 1.0, "bullet_speed": 260, "bullet_size": 2.5, "recoil": 150,
  "explosion": { "radius": 36, "damage": 90, "terrain_damage": 200, "knockback": 320 } }
```

Kinds: `gun`, `melee`, `throwable`. Useful knobs: `pellets`, `spread`, `auto`, `charge_time` (+`charge_scales`),
`spin_up`, `pierce`, `bullet_gravity`, `explosion`, `fire`, `shield`, `sticky`, `cursed`, `impact`, `spawn_weight`.

## Maps

Starter maps are generated by `python3 tools/gen_maps.py` (helpers for buildings, fire escapes etc.):
Warehouse and Rooftops (one screen, good for couch play), Downtown (160×64: street, six buildings,
fire escapes, subway tunnel) and Factory (128×72: catwalk tiers, offices, death pit). On big maps the
camera follows you in single player and frames everyone in multiplayer; arrows at the screen edge point
to off-screen fighters.

## Adding maps

Drop a `.json` in `data/maps/` (or `user://maps/`): `{"name": "...", "tiles": ["....", ...]}`. Any size works; 60×34 fits one screen. Falling off the bottom kills you.

| Char | Tile | | Char | Entity |
|---|---|---|---|---|
| `D` | dirt (30hp) | | `P` | player spawn |
| `S` | brick (90hp) | | `X` | weapon spawner |
| `W` | wood (28hp, burns) | | `C` | crate (breaks, may drop loot) |
| `G` | glass (4hp) | | `B` | explosive barrel |
| `K` | concrete (140hp) | | `.` | empty |
| `M` | metal (indestructible) | | | |
| `-` | wooden one-way platform | | | |
| `H` | ladder | | | |

Lowercase `d s w k` = background wall (decoration, no collision). Destroyed brick/wood/dirt leaves
background wall behind. Material stats live in `scripts/world/tile_mats.gd`.

## Architecture notes

- **Input → simulation seam:** fighters only read `InputFrame`s (`scripts/core/input_frame.gd`, packs to 10 bits).
  Keyboard, gamepad, bot and scripted test sources all produce them; `Arena` ticks fighters in fixed order.
  Online play = send frames / snapshots over the network and add a network `InputSource`.
- **Bots** (`bot_source.gd` + `nav.gd`) pathfind over the live tile grid, so they adapt to blown-up terrain.
- Terrain is a TileMapLayer with per-tile HP; cracked looks are extra atlas columns.

## Testing (headless)

```sh
godot --headless --fixed-fps 60 -- --scenario all          # scripted mechanic tests (ladders, dive, disarm, ...)
godot --headless --fixed-fps 60 -- --bots 4 --map warehouse --quit-after 180   # bot match + stats
```

More flags: `--quick` (you + 3 bots), `--trace`, `--trace-every N`, `--screenshot PATH`. See `scripts/game/game.gd`.
